Sobre mim

Trabalho com análise e auditoria de dados em larga escala. No dia a dia, uso SQL Server para cruzar bases, reconciliar informações entre sistemas e rastrear divergências até a causa raiz na origem — incluindo inconsistências de estoque e custo dentro do ERP. Python e Excel avançado completam o conjunto, do tratamento dos dados até a entrega do resultado.

Minha especialização é dados fiscais: SPED Fiscal/EFD e documentos eletrônicos (NF-e/NFC-e), um domínio em que precisão não é opcional — um número errado vira problema regulatório. Essa régua alta de integridade é o que levo para qualquer contexto de dados.

Sou estudante de Engenharia de Software na Univille, com formação técnica em Desenvolvimento de Sistemas pela Escola SESI de Referência, e busco atuar com análise de dados e BI.

Projetos

Análises e investigações feitas em contexto profissional de auditoria, sobre bases de dados de grande volume. Cada uma parte de uma pergunta: onde está a divergência, e por quê?

Investigação de Divergências de Estoque e Custo

Análise em SQL Server para rastrear divergências de estoque e custo até a origem no ERP. O trabalho envolveu cruzar bases de sistemas diferentes, isolar onde os números deixavam de bater e identificar a causa raiz — não apenas apontar que havia diferença, mas explicar de onde ela vinha.

  • SQL Server
  • Análise de causa raiz
  • Dados de ERP

Reconciliação e Auditoria de Dados Fiscais

Consultas SQL para reconciliar informações fiscais entre sistemas e validar consistência antes da entrega ao cliente, transformando uma conferência manual e demorada em uma verificação sistemática e repetível.

  • SQL Server
  • Reconciliação
  • Qualidade de dados

Validação de Integridade em SPED Fiscal/EFD

Identificação e correção de inconsistências recorrentes (erros 127-A, 118-E1, 452-A, entre outros) nos registros C100, C170, C180, C185 e C190. Mapear os padrões por trás dos erros permitiu tratá-los de forma sistemática, em Python e PowerShell.

  • Python
  • PowerShell
  • SPED/EFD

Extração de Dados de XML (NF-e/NFC-e)

Recuperação de documentos fiscais dentro de arquivos compactados, com busca baseada no conteúdo do XML em vez do nome do arquivo — necessário porque as chaves nos nomes estavam inconsistentes e a busca convencional não encontrava os registros.

  • Python
  • Extração de dados
  • XML

Processamento Confiável de Grandes Volumes

Rotina de processamento em lote com checkpoint e retomada: se a execução falha no meio de milhares de arquivos, ela retoma de onde parou em vez de recomeçar. Garante que o dado entregue ao cliente esteja completo, sem lacunas silenciosas.

  • Python
  • Processamento em lote
  • Integridade de dados
